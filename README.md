# ファルダゴ ストーリー

立ち絵と背景でストーリーが進む、ノベルゲーム風の再生アプリです。スマホ縦画面向け。

- 話している人は少し大きく明るく、話していない人は少し小さくグレーに
- 表情の切り替え（通常・笑顔・怒り・困り・驚き。自由に追加可）
- 選択肢で、その後のセリフが分岐
- 背景の切り替え（フェード）
- ログ、オート送り、つづきから（端末に自動保存）

## フォルダ構成

```
faldago-story/
├─ index.html          … 再生画面（タイトル → シナリオ選択 → 再生）
├─ editor.html         … シナリオエディタ
├─ scenarios/
│   ├─ index.json      … タイトル画面に出すシナリオの一覧
│   └─ sample.json     … サンプル（分岐2か所）
└─ images/
    ├─ chara/          … 立ち絵（キャラID_表情キー.拡張子）
    └─ bg/             … 背景
```

## GitHub Pages に置く

1. GitHub で新しいリポジトリを作る（例：`faldago-story`）
2. 「Add file → Upload files」で、このフォルダの中身をフォルダ構成ごとアップロード
3. 「Settings → Pages」で Branch を `main`・フォルダを `/ (root)` にして Save
4. 数分後に表示される URL（`https://ユーザー名.github.io/faldago-story/`）をスマホで開く

※ パソコンで index.html を直接ダブルクリックすると、シナリオ一覧が読めません（ブラウザの仕様）。その場合はタイトル画面の「シナリオファイルを開く」から .json を選べば再生できます。

## 立ち絵を本物に差し替える

今入っている立ち絵は仮画像（SVG）です。

1. 背景を透過した PNG を用意し、`leo_smile.png` のように「キャラID_表情キー.png」で名前を付ける
   - キャラID：`leo` `tierra` `wayne` `romdo`
   - 表情キー：`normal` `smile` `angry` `trouble` `surprise`
2. `images/chara/` に入れる
3. エディタの「キャラ」タブで、拡張子を `png` にして「命名ルールで一括設定」を押す
4. 「ファイル」タブから JSON を書き出し、`scenarios/` のファイルを置き換える

立ち絵は**縦長・足元（または腰）が画像の下端にそろっている**と、きれいに並びます。

## シナリオを作る

1. editor.html を開く（再生画面のタイトルからも行けます）
2. 「シナリオ」タブでステップを追加・編集。各カードの「▶」でそこからテストプレイ
3. 「ファイル」タブでタイトル・ファイル名を決めて「JSONを書き出す」
4. 書き出したファイルを `scenarios/` に置き、`scenarios/index.json` に名前を追記

```json
[
  "sample.json",
  "chapter1.json"
]
```

### ステップの種類

| 種類 | できること |
|---|---|
| セリフ | キャラ・表情・左右・動き（ぴょん／ぶるっ）を指定してしゃべる |
| ナレーション | 名前なしの地の文 |
| 選択肢 | 2〜4択。選んだら指定したラベルへジャンプ |
| 背景 | 背景を切り替え。「立ち絵をすべて下げる」で場面転換 |
| ラベル | ジャンプ先の目印 |
| ジャンプ | 指定したラベルへ飛ぶ（分岐後に合流させるときに使う） |
| 登場／退場 | しゃべらずに立ち絵だけ出す・下げる |
| 終了 | シナリオの終わり |

### 分岐の書き方

```
選択肢  「食べてみる」→ eat ／「様子を見る」→ wait
ラベル eat
  セリフ…
  ジャンプ → after
ラベル wait
  セリフ…
ラベル after   ← ここで合流
```

エディタ上部に、ジャンプ先が見つからない・キャラや表情が見つからないなどの問題が自動で表示されます。

## メモ

- 端末に保存するデータは `fstory_` で始まる名前で、他のアプリとぶつかりません
- エディタの下書きは端末ごとです。別の端末で続けるときは JSON を書き出して読み込んでください
- 【要確認】「選んだ選択肢を覚えて、後で別のセリフにする（フラグ）」は未対応です。必要なら追加できます
